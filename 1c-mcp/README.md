# Мост «1С ↔ Claude»

Программа подключает вашу базу 1С к Claude Desktop. После установки вы просто пишете
Claude вопросы о работе, а он сам берёт данные из 1С:

- «Сколько регистраторов DS-7608 на складе и почём?»
- «Какие камеры Hikvision продали больше всего в октябре и кому?»
- «Сравни продажи по месяцам за этот год, покажи график»
- «Кто из контрагентов должен больше 50 000 ₽? Сделай Excel-таблицу»
- «Что из ходового товара закончится через неделю при таком темпе продаж?»

**Только чтение.** Мост умеет лишь смотреть структуру базы и выполнять запросы на языке
запросов 1С. Этот язык не умеет изменять данные, поэтому мост не может испортить базу.

> Данные, о которых вы спрашиваете, уходят в Claude, чтобы он мог ответить, —
> так же, как если бы вы скопировали их в чат.

## Что нужно

- Компьютер с 1С (Windows 11), на нём Claude Desktop — <https://claude.ai/download>
- Python 3.12 — <https://www.python.org/downloads/windows/>

### Какой Python скачать

Разрядность Python должна совпадать с разрядностью 1С:

- есть папка `C:\Program Files\1cv8\8.3.13.1513` → **Windows installer (64-bit)**
- есть только `C:\Program Files (x86)\1cv8\8.3.13.1513` → **Windows installer (32-bit)**

При установке Python оставьте галочку **«Use admin privileges when installing py.exe»** /
**«py launcher»** (она стоит по умолчанию).

## Установка (≈10 минут)

1. Скопируйте папку `1c-mcp` в `C:\1c-mcp` (лучше без русских букв и пробелов в пути).
2. Двойной щелчок по `setup.bat` → «Да» на вопрос о правах администратора.
3. Программа сама:
   - найдёт 1С и зарегистрирует её COM-коннектор;
   - установит нужные библиотеки;
   - спросит путь к базе, пользователя и пароль 1С;
   - проверит подключение — покажет 5 товаров из номенклатуры;
   - пропишет мост в настройки Claude Desktop.
4. Полностью закройте Claude Desktop (значок у часов → **Quit**) и откройте снова.
5. В Claude нажмите значок инструментов под полем ввода — там должен быть **1c**.
   Спросите: «Проверь подключение к 1С».

Пароль 1С сохраняется в файле настроек Claude Desktop на этом компьютере.
Если поменяли пароль в 1С — просто запустите `setup.bat` ещё раз.

## Если что-то не работает

| Сообщение | Что делать |
|---|---|
| Нужен Python N-бит | Скачать Python нужной разрядности (см. выше) и запустить `setup.bat` снова |
| Неправильное имя или пароль | Проверить пользователя и пароль, с которыми входите в 1С |
| Не обнаружено свободной лицензии | COM-подключение занимает лицензию, как ещё один сеанс. На том же компьютере обычно хватает одной; если нет — закрыть лишние сеансы 1С |
| Ошибка блокировки / монопольный режим | Закрыть конфигуратор и обновление базы |
| Claude не видит «1c» | Перезапустить Claude Desktop через Quit; в Claude: Settings → Developer → должна быть строка «1c» без ошибки |

Проверить мост без Claude: в папке `C:\1c-mcp` выполнить
`.venv\Scripts\python.exe onec_mcp.py --test` (переменные ONEC_BASE, ONEC_USER, ONEC_PASSWORD
задаёт `setup.bat`; для ручной проверки задайте их сами).

## Как устроено

- `onec_mcp.py` — MCP-сервер. Claude Desktop запускает его сам. Сервер подключается к 1С через
  `V83.COMConnector` и даёт Claude четыре инструмента: `info`, `list_metadata`,
  `describe_object`, `run_query`.
- `setup.ps1` / `setup.bat` — установщик.
- Сервер подсказывает Claude, что в базе «Агент Плюс: УТ 10.3» и какие там типовые регистры,
  а реальные имена реквизитов Claude проверяет сам — конфигурация доработана.
